## 待办清单

### P0-高

1. **可信回答失败时剔除亮点**
   - 问题：回答被判为“素材不足”后，亮点仍可导出。证据：`src/lib/validate.ts:47-49,59-82`。
   - 修复建议：将回答可信度作为亮点保留条件；剔除时记录具体原因。
   - 验收标准：任一必需追问无法给出可信回答的亮点不出现在简历或 PDF 中，页面展示剔除原因。
   - 涉及文件：`src/lib/validate.ts`、`src/app/resume/page.tsx`。

2. **补齐事实与亮点的内容溯源校验**
   - 问题：事实正文可脱离原话修改；亮点只校验数字和引用 ID，新增非数字内容仍可能通过。证据：`src/app/vault/page.tsx:88-96`；`src/lib/validate.ts:35-46`。
   - 修复建议：事实修改时要求同步提供真实来源或重新确认；对亮点增加基于所引事实的内容核验，无法确认时阻止交付并说明原因。
   - 验收标准：在事实原话没有提及某技能、职责或效果时，含该内容的亮点不能进入导出结果；每条导出亮点均能显示有效来源。
   - 涉及文件：`src/app/vault/page.tsx`、`src/lib/validate.ts`、`src/app/api/resume/route.ts`。

3. **把最终亮点关联到 JD 要求**
   - 问题：当前逐条表止于履历事实，无法复核最终写入简历的亮点对应哪条要求。证据：`src/app/match/page.tsx:93-135`；`src/lib/types.ts:42-51`。
   - 修复建议：为要求和亮点建立可追踪的关联，并在生成后展示最终对应关系。
   - 验收标准：每条被宣称覆盖的 JD 要求可点开查看对应的最终亮点及其来源；未覆盖项明确显示缺口。
   - 涉及文件：`src/lib/types.ts`、`src/app/api/match/route.ts`、`src/app/api/resume/route.ts`、`src/app/match/page.tsx`。

### P0-中

4. **校验采集完成条件**
   - 问题：回答两轮后即可入库，缺少对岗位、时间及具体行为／成果的入库校验。证据：`src/app/collect/page.tsx:98,158-159,193-197`。
   - 修复建议：在整理与保存阶段检查必要字段和事实具体性，不足时给出有针对性的补充问题。
   - 验收标准：过于笼统的两轮回答不能直接保存为合格经历；页面明确指出需要补充的细节。
   - 涉及文件：`src/app/collect/page.tsx`、`src/app/api/extract/route.ts`。

5. **处理无匹配 JD 与异常格式**
   - 问题：无匹配时仍可生成；只以长度判断 JD 是否有效。证据：`src/app/api/match/route.ts:10-12`；`src/app/match/page.tsx:93-116,137-140`。
   - 修复建议：识别缺少可解析职责／要求的输入；全无匹配时提供明确提示和补充履历入口。
   - 验收标准：无有效要求的 JD 提示重贴；全无匹配时不生成声称“定向”的亮点，且明确告知缺口。
   - 涉及文件：`src/app/api/match/route.ts`、`src/app/match/page.tsx`。

6. **实现 P0 交付选项**
   - 问题：只有固定版式，无模板选择、证件照入口和免费版水印。证据：`src/app/resume/page.tsx:10-16,67-89,107-166`；`src/lib/exportPdf.ts:66-89`。
   - 修复建议：先实现基础模板选择、可选照片和免费导出水印，并让预览与 PDF 一致。
   - 验收标准：用户可选基础模板；缺照片可导出；免费 PDF 带水印；所选样式与导出一致。
   - 涉及文件：`src/app/resume/page.tsx`、`src/lib/exportPdf.ts`。

## 其他风险

- **个人信息仅在本机持久化的可靠性风险：**姓名、电话、邮箱及履历存在 `localStorage`；写入失败时被静默忽略，界面状态仍更新，用户可能误以为已保存。证据：`src/lib/storage.ts:5-12,35-45`；`src/app/resume/page.tsx:70-77`。
- **备份导入缺少结构校验：**导入函数将 JSON 中对应键直接写入存储；履历库随后直接访问 `experiences.reduce` 和 `e.facts`，格式错误的备份可能使页面报错。证据：`src/lib/storage.ts:63-67`；`src/app/vault/page.tsx:26-29,37`。
- **部分生成失败可能静默缺段：**简历接口使用 `Promise.allSettled`，只要一段成功就返回成功结果，未向用户报告其余经历生成失败；页面随后以原始事实填充无亮点经历。证据：`src/app/api/resume/route.ts:23-42`；`src/app/resume/page.tsx:58-61,122-133`。
- **内置浏览器无法直接交付 PDF：**检测到微信等内置浏览器后只提供长图，需用户转到外部浏览器才能下载 PDF；与 P0 的直接 PDF 导出体验有差距。证据：`src/app/resume/page.tsx:33-40,93-103`。
- **模型错误信息直接返回前端：**上游响应文本会进入错误消息，路由再将该消息返回用户；具体是否包含敏感信息需结合服务商错误响应人工确认。证据：`src/lib/llm.ts:43-53`；`src/app/api/match/route.ts:31-33`。
